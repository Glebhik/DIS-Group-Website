# DIS Group — Website

Corporate website for **DIS Group (Dismelt Irish Services Group)**.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Full single-page website |
| `style.css` | All styles — layout, components, responsive |
| `script.js` | Navbar scroll, animations, form handling, counters |
| `README.md` | This file |

## Sections

1. **Hero** — Headline, stats, CTA buttons
2. **About** — Company overview, founder, values
3. **Services** — 5 service cards (Aluminium Recycling, Vehicle Dismantling, Scrap Metal Supply, Sustainable Logistics, Circular Economy)
4. **Sustainability / ESG** — Environmental metrics, compliance, reporting
5. **Why Ireland** — 6 strategic advantages
6. **Partners & Buyers** — 4 audience segments + CTA banner
7. **Contact** — Contact info + enquiry form

## Design

- Colour palette: dark blue `#0a1628`, green `#1a7a4a` / `#27ae60`, black
- Fonts: Segoe UI / system sans-serif
- Mobile-first responsive layout
- Smooth scroll, scroll-reveal animations, animated counters
- Fixed navbar with scroll-activated background
- Mobile hamburger menu
